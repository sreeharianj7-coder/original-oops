About The System

The system digitizes hostel attendance and allows students to mark attendance after their hostel location is verified, while hostel administrators can monitor attendance across students.

📍

Location-Verified Student Attendance

Eliminates proxy attendance and manual paper registers. When students mark attendance, high-precision GPS coordinates are calculated by the Java backend using the Haversine distance algorithm against their allocated hostel boundary.

🛡️

Hostel Administrator Dashboard

Provides hostel wardens with real-time visibility into daily roll-calls, attendance rates, student searches, and historical date filtering to ensure residential safety across hostel blocks.

System Workflow

How It Works

Two tailored workflows for students and hostel administrators.

Student Portal

Student Attendance Workflow

1.
Register & Login: Secure login to the student portal.
2.
Verify Location: Request browser coordinates via Geolocation API.
3.
Backend Validation: Java backend calculates Haversine distance against hostel coordinates.
4.
Mark Attendance: If within radius, record is persisted in MySQL and calendar updates.
Admin Portal

Administrator Workflow

1.
Admin Login: Authenticate into the warden monitoring dashboard.
2.
Select Date & Hostel: View attendance overview for the selected evening.
3.
Monitor Overview: Review Present, Absent, and Not Marked counts.
4.
Student Search & Audit: Search students and view individual attendance histories.
